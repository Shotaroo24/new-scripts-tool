# srtgen

アラビア語の原稿テキストをブラウザに貼り付けると、Filmora読み込み用のSRT字幕ファイルをダウンロードできるツールです。

詳細な仕様は [`srtgen-web-spec.md`](./srtgen-web-spec.md) を参照してください。

## 使い方

1. `index.html` をブラウザで開く（ダブルクリックでも、静的ホスティング上でも同じように動作します）
2. 左側のテキストエリアにアラビア語の原稿を貼り付ける
3. 右側にリアルタイムで分割結果・タイムコードのプレビューが表示される
4. 必要なら「読み速度（cps）」「BOM付き出力」を設定
5. 「SRTファイルをダウンロード」を押すと `subtitles_YYYYMMDD_HHMM.srt` がダウンロードされる

原稿テキストはブラウザ内で処理が完結し、外部には一切送信されません（サーバー・DB・保存機能なし）。

## 技術構成

- `index.html` 1枚のみで完結（HTML / CSS / Vanilla JavaScript を内包）
- フレームワーク・ビルドステップ・外部ライブラリ・CDN依存なし
- 対応ブラウザ: モダンブラウザ（Chrome / Edge / Safari）

## 原稿テキストの扱い（厳守事項）

以下の3つ以外、原稿テキストを一切改変しません（タシュキールの除去、数字表記の統一、Unicode正規化などは行いません）。

1. 区切り文字のうち「削除」対象（`.` `،` `,`）の削除
2. 各字幕テキスト（各行）の前後の空白トリム
3. 区切り文字を挟まない改行を、同一字幕内の2行目として扱う処理

タイムコードは各字幕のdurationを個別丸めせず、**累積秒数を保持して都度ミリ秒に丸める方式**（累積丸め方式）で算出しているため、字幕枚数が多くなっても丸め誤差が蓄積しません。

## テスト

`tests/logic.test.js` は `index.html` 内の分割・タイムコード算出ロジックをそのまま抽出して実行する回帰テストです（ロジックの二重管理を避けるため、コードを複製せず `index.html` から読み込んで実行します）。`index.html` を編集した際は、以下のコマンドで仕様書第8節の受け入れテスト相当の項目が壊れていないか確認してください。

```
node tests/logic.test.js
```

Node.js 以外の依存はありません。

## デプロイ（Vercel）

静的ファイルのみで構成されているため、Vercelにゼロコンフィグでデプロイできます。

1. このリポジトリを GitHub 経由で Vercel の「Add New Project」から Import する
2. ビルドコマンド・出力ディレクトリの設定は不要（`index.html` がそのまま配信される）

認証やアクセス制限は不要です（原稿はクライアント内で完結し、サーバーには何も送られないため）。
