# srtgen — アラビア語原稿 → SRT変換 Webツール 仕様書

## 1. 目的とスコープ

アラビア語の原稿テキストをブラウザ上の入力欄に貼り付けると、CapCut読み込み用のSRTファイルをダウンロードできるWebツール。

**スコープ外（実装しないこと）:**
- カット編集、シーン検出、カット点スナップ
- 動画尺と原稿量の整合チェック
- タイミングの微調整機能（CapCut上で手動調整する）
- サーバーサイド処理、DB、ログイン、保存機能の一切

## 2. 技術要件

- **HTML + CSS + Vanilla JavaScript で完結させる**（ローカルファイル間の分割は可。`<script src>` / `<link rel="stylesheet">` のみで読み込む）
- フレームワーク・ビルドステップ・外部ライブラリ・CDN・外部フォント読み込みは一切使わない
- すべての処理はクライアントサイド（ブラウザ内）で完結する。原稿テキストがネットワークに送信されることは一切ない
- ローカルでダブルクリックして開いても、静的ホスティング（Vercel等）にデプロイしても、同一に動作すること
- 対応ブラウザ: モダンブラウザ（Chrome / Edge / Safari）。IE対応不要
- レスポンシブ対応: デスクトップ2カラム、モバイル1カラム縦積み

## 3. UI要件

### 3.1 レイアウト

- **左ペイン（入力）**: 原稿貼り付け用テキストエリア + 英訳テキストエリア（併記機能。詳細は `srtgen-timeline-spec.md` 4節）+ 設定 + ダウンロードボタン
- **右ペイン（対応付け確認ビュー）**: アラビア語クリップと英訳行の対応付け確認リスト + 統計。時刻中心のプレビューはタイムラインモードへ移した（`srtgen-timeline-spec.md` 5節）
- ヘッダー: ツール名「srtgen」と一行説明のみ。装飾は最小限

### 3.2 入力テキストエリア

- `dir="rtl"` を指定し、アラビア語が右から左に自然に表示されること
- フォントサイズ17px以上、行間ゆったり（アラビア語の可読性優先）
- `spellcheck="false"`
- 貼り付け・タイプの両方に対応（入力のたびに対応付け確認ビューが即時更新される）
- 英訳テキストエリアは `dir="ltr"`。1行 = 1クリップで、区切り文字によるパースは行わない（詳細は `srtgen-timeline-spec.md` 4節）

### 3.3 設定（2つのみ。凝った設定機構は作らない）

- **読み速度（cps）**: 数値入力。デフォルト12、小数可（step 0.5）
- **BOM付き出力**: チェックボックス。デフォルトOFF

### 3.4 対応付け確認ビュー

- 入力のたびに即時再計算・再描画（変換ボタンは不要。ダウンロードボタンのみ）
- 1行ごとに表示: 連番 / アラビア語本文（`dir="rtl"`、2行字幕は改行を保持して表示 = `white-space: pre-wrap`）/ 対応する英訳（`dir="ltr"`）/ 文字数
- アラビア語件数と英訳行数が一致しない場合は件数のみの警告文を表示し、対応する相手が存在しない行を強調する（詳細は `srtgen-timeline-spec.md` 4.2節）
- 上部に統計: 総枚数、総尺（MM:SS.s形式）
- 入力が空のときは案内文（空状態メッセージ）を表示
- テキストはHTMLエスケープして描画すること（XSS対策）

### 3.5 ダウンロードボタン

- 押すとSRTファイルがダウンロードされる（Blob + a[download] 方式）
- ファイル名: `subtitles_YYYYMMDD_HHMM.srt`
- 字幕0枚のときはdisabled

## 4. 分割ルール

### 4.1 区切り文字

以下の文字を字幕の**区切り**として扱う:

| 文字 | コードポイント | 出力への扱い |
|---|---|---|
| `.` ピリオド | U+002E | **削除**（字幕テキストに含めない） |
| `،` アラビア語コンマ | U+060C | **削除** |
| `,` ラテンコンマ | U+002C | **削除** |
| `؟` アラビア語疑問符 | U+061F | **残す**（字幕テキスト末尾に含める） |
| `?` 疑問符 | U+003F | **残す** |
| `!` 感嘆符 | U+0021 | **残す** |
| `—` emダッシュ | U+2014 | **削除** |

### 4.2 区切り文字の連続

区切り文字が連続する場合（例: `؟!` や `...`）は1つの区切りとして扱い、**空の字幕を生成しない**。連続部分に「残す」系の文字が含まれる場合は、直前の字幕のテキスト末尾に付加する。

### 4.3 接続詞分割は実装しない

接続詞の前には基本的にコンマがあるため、区切り文字ベースの分割のみで足りる。形態素解析等は一切不要。

### 4.4 字幕内改行（2行字幕）

- 基本は1枚1行
- 原稿内で、**区切り文字を挟まずに改行されている箇所**は、同一字幕内の改行（2行字幕）として扱う
- 各行は前後トリムし、空行は除去する
- ツール側で自動的に長文を折り返す処理は**実装しない**（長い一文は原稿側で調整する）

### 4.5 空セグメントの除去

分割後、テキストが空または空白のみのセグメントは字幕として出力しない。連番も詰める。

## 5. 原稿テキストの扱い（厳守事項）

- **原稿テキストは一切改変しない。** 以下をすべて禁止する:
  - タシュキール（母音記号）の除去
  - 数字表記の統一（アラビア数字⇔インド数字の変換等）
  - RLM（U+200F）等の制御文字の挿入・除去
  - Unicode正規化（NFC/NFD変換等）
  - 文字の置換・修正の一切
- 許可される加工は以下の**3つのみ**:
  1. 4.1で定義した「削除」区切り文字（`.` `،` `,`）の削除
  2. 各字幕テキスト（各行）の先頭・末尾の空白文字のトリム
  3. 4.4で定義した字幕内改行の処理
- 文字の走査はコードポイント単位で行うこと（JSでは `Array.from(text)` を使い、サロゲートペアを壊さない）

## 6. タイムコード割り当て

- 各字幕の表示時間（秒） = 表示テキストの文字数 ÷ cps
  - 文字数は、区切り文字削除・トリム後の**最終的な表示テキスト**で数える
  - スペース込み、改行文字は数えない
  - コードポイント単位でカウント（`Array.from(s).length`。タシュキールも1文字として数えてよい）
- 最短・最長表示時間の制約は**設けない**
- 字幕間ギャップは**0秒**: 前の字幕の終了時刻 = 次の字幕の開始時刻
- 開始時刻は `00:00:00,000` から累積
- **累積丸め方式**でミリ秒化すること: 累積秒数（浮動小数）を保持し、各時刻を都度 `Math.round(累積秒 × 1000)` でミリ秒化する。各字幕のdurationを個別に丸めて足す方式は累積誤差が出るため禁止

## 7. 出力フォーマット

標準SRT形式:

```
1
00:00:00,000 --> 00:00:02,500
النص الأول

2
00:00:02,500 --> 00:00:05,000
النص الثاني
```

- 連番は1始まり
- タイムコードは `HH:MM:SS,mmm`（カンマ区切りミリ秒、各桁ゼロ埋め）
- 各字幕ブロックの後に空行
- 改行コード: LF（CapCut実機テストで問題があればCRLFに切り替えられるよう、コード上は定数1箇所で管理）
- エンコーディング: UTF-8（デフォルトBOMなし、チェックボックスONでBOM `U+FEFF` を先頭に付加）

## 8. 受け入れテスト

以下を確認すること（ブラウザで手動確認 or 変換ロジックを関数として切り出して簡易テスト）:

1. 区切り文字で正しく分割される
2. `.` `،` `,` が出力テキストから消えている
3. `؟` `!` `—` が出力テキストに残っている
4. 区切り文字連続時（`...` `؟!` 等）に空字幕が生成されない
5. 字幕内改行（区切りなしの原稿改行）が2行字幕になり、SRT内でも2行で出力される
6. タイムコードがギャップ0で連続している（前の終了 = 次の開始）
7. cps=12のとき、24文字の字幕がちょうど2.000秒になる
8. タシュキール付きテキストが無改変（区切り削除とトリム以外）で出力される
9. 多数の字幕（50枚以上）でも累積丸め誤差による時刻ズレがない
10. 入力を全消ししたとき、プレビューが空状態に戻り、ダウンロードボタンがdisabledになる
11. ローカルファイルとして開いた場合と、静的ホスティング上で開いた場合の両方で動作する

## 9. デプロイ

- 静的ファイル1枚なので、Vercelに静的サイトとしてデプロイ可能な構成にする（`index.html` 1枚のリポジトリで可）
- 認証・アクセス制限は不要（原稿はクライアント内で完結し、サーバーに何も送られないため）
